# HackerNews RR7

A fast Hacker News client built with TanStack Start, React 19, and Cloudflare Workers.

## Features

- Server-side rendering on Cloudflare Workers
- Infinite story feeds with router, service worker, and LRU caching
- Post detail pages with lazy-loaded comment threads
- User profiles with submitted stories and comments
- PWA support with offline fallback and update prompts
- Auto-refresh on tab focus and visibility changes

## Tech Stack

- **Framework**: TanStack Start and TanStack Router
- **UI**: React 19
- **Runtime**: Cloudflare Workers
- **Build**: Vite 8
- **Language**: TypeScript 6 in strict mode
- **Styling**: CSS Modules
- **Tooling**: Bun, Biome, Wrangler

## Requirements

- Node.js 24
- Bun

## Getting Started

```bash
bun install
bun run dev
```

The dev server runs at `http://localhost:5173`.

## Scripts

```bash
bun run dev              # Start Vite dev server
bun run build            # Build client/server output, then typecheck
bun run preview          # Preview the production build
bun run deploy           # Build and deploy to Cloudflare Workers
bun run lint             # Run Biome lint
bun run format           # Run Biome fixes
bun run format:check     # Run Biome without writing changes
bun run typecheck        # Run TypeScript only
bun run typegen          # Generate Cloudflare Worker types
bun run update:deps      # Open npm-check-updates UI
```

## Architecture

The app uses three cache layers:

- Service worker cache for Hacker News API and static assets
- TanStack Router loader cache with short stale times
- In-memory LRU caches for story IDs, posts, users, and post details

Story feeds load IDs first, then fetch posts in batches with a six-request concurrency limit. Comment pages fetch the first two levels up front and load deeper replies on demand.

## Deployment

Deploy with Wrangler:

```bash
bun run deploy
```

Requires Cloudflare account and `wrangler` authentication.
